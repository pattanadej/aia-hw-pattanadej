# ตัวชี้วัดเฉพาะอุตสาหกรรมที่ควรดึง

รายการทั่วไปสำหรับหุ้นไทย เลือกกลุ่มที่ใกล้ธุรกิจของบริษัทที่สุด (บริษัทอาจคร่อมหลายกลุ่ม) ดึงเฉพาะตัวที่บริษัทเปิดเผยจริงในงบ/MD&A/Oppday ตัวไหนไม่เปิดเผยให้ข้าม ห้ามประมาณเอง ทุกตัวเลขต้องมีที่มาและเทียบ YoY เป็นหลัก ตรวจนิยามของบริษัท (เช่น SSSG นับสาขาที่เปิดมากี่เดือน) ก่อนเทียบงวด

เกณฑ์ทั่วไปทุกกลุ่ม: ถ้าบริษัทเลิกเปิดเผยตัวชี้วัดที่เคยเปิดเผย ให้บันทึกเป็นประเด็นเด่น

| กลุ่ม | ตัวชี้วัดที่ควรดึง |
|---|---|
| ค้าปลีก/ร้านอาหาร | SSSG (ยอดขายสาขาเดิม) · จำนวนสาขา เปิดใหม่/ปิด · ยอดขายต่อสาขา · traffic และ ticket size · สัดส่วนช่องทางออนไลน์ · อัตรากำไรขั้นต้น (ผลของ mix/ต้นทุนสินค้า) · ค่าเช่าและค่าแรงต่อยอดขาย |
| ผลิต/ส่งออก | ปริมาณขาย vs ราคาขาย · อัตราการใช้กำลังผลิต · ต้นทุนวัตถุดิบหลักและค่าพลังงาน · ผลของ FX (รายได้ส่งออกเป็นสกุลต่างประเทศ + hedging) · สัดส่วนรายได้ตามภูมิภาค/ลูกค้ารายใหญ่ · ค่าระวางและภาษี/มาตรการการค้า |
| วัสดุ/พลังงาน/ปิโตรเคมี/เหล็ก/ปูนซีเมนต์/กระดาษและบรรจุภัณฑ์ | ราคาสินค้าและราคาวัตถุดิบ → spread · ปริมาณขาย · utilization · กำไรจากสต็อก (inventory gain/loss) · ค่าพลังงานต่อหน่วย · ผลตัดจำหน่าย/ด้อยค่าสินทรัพย์ |
| ธนาคาร/สินเชื่อ/ประกัน | NIM · NPL ratio และ NPL coverage · credit cost · การเติบโตสินเชื่อ · เงินฝาก/CASA · cost-to-income · CAR/CET1 · รายได้ค่าธรรมเนียม · (ประกัน: combined ratio, ยอดเบี้ยรับ, อัตราส่วนเงินกองทุน) |
| อสังหาริมทรัพย์ | ยอดขายรอรับรู้ (backlog) · ยอดขาย presales · ยอดโอน · อัตราปฏิเสธสินเชื่อ/ยกเลิก · มูลค่าโครงการเปิดใหม่ · สินค้าคงเหลือพร้อมโอน · อัตรากำไรขั้นต้นโครงการ · D/E และหนี้ระยะสั้น · (ให้เช่า: occupancy, rental rate) |
| ท่องเที่ยว/โรงแรม/สายการบิน | Occupancy · ADR · RevPAR · จำนวนผู้โดยสาร/load factor · yield · สัดส่วนนักท่องเที่ยวตามประเทศ · ต้นทุนเชื้อเพลิง |
| สื่อสาร/เทคโนโลยี/ซอฟต์แวร์ | จำนวนผู้ใช้ · ARPU · churn · ARR/รายได้ซ้ำ · backlog สัญญา · capex ต่อรายได้ · ค่าตัดจำหน่ายคลื่น/สินทรัพย์ |
| ก่อสร้าง/รับเหมา | Backlog · งานใหม่ที่ได้ (new awards) · อัตรากำไรขั้นต้นตามความคืบหน้า · การปรับประมาณการต้นทุนโครงการ · ลูกหนี้ตามสัญญา/สินทรัพย์ตามสัญญา |
| สาธารณูปโภค/โรงไฟฟ้า/โครงสร้างพื้นฐาน | กำลังการผลิตติดตั้ง · ปริมาณขายไฟ · อัตราค่าไฟ/ค่า Ft หรือค่าผ่านทาง · ความพร้อมจ่าย · ปริมาณจราจร/ผู้ใช้ · ภาระหนี้และ DSCR |
| เกษตร/อาหาร/เครื่องดื่ม | ราคาสินค้าเกษตรและวัตถุดิบ · ปริมาณขาย · อัตรากำไรขั้นต้น · ส่วนแบ่งตลาด · สัดส่วนส่งออก · FX |
| สุขภาพ/โรงพยาบาล | จำนวนผู้ป่วยนอก/ใน · รายได้ต่อผู้ป่วย · สัดส่วนผู้ป่วยต่างชาติ · อัตราการใช้เตียง · ค่าใช้จ่ายแพทย์ · ลูกหนี้ประกันสังคม/ประกันเอกชน |
| ทุกกลุ่ม (ฐานะการเงิน) | หนี้สินมีดอกเบี้ยสุทธิ/EBITDA · D/E · ดอกเบี้ยจ่ายและ interest coverage · capex vs กระแสเงินสดดำเนินงาน · เงินปันผลจ่ายเทียบนโยบาย · หนี้ที่ครบกำหนดใน 12 เดือน |

หมายเหตุ: ถ้าบริษัทเป็นกลุ่มที่ไม่อยู่ในตาราง ให้ถามตัวเองว่า "ผู้บริหารพูดถึงตัวเลขอะไรซ้ำ ๆ ในทุก MD&A" แล้วใช้ตัวนั้น
